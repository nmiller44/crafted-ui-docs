<Section title="Motion Strategy">
Crafted UI uses brief transitions to communicate component state changes, such as a popup opening or closing. The shared motion utility applies a 150 ms duration with ease-out easing to supported transitions.

This policy currently applies to Drawer, Menu, Modal, Select, and Combobox. Their transitions reflect the interaction: Drawer panels slide with a fading backdrop, while popup-style components use scale and opacity changes. Motion is supplemental; opening, closing, selection, keyboard behavior, and dismissal do not depend on an animation completing.
</Section>

<Section title="No Motion">
Set `nomotion` on a supported component to remove its opening and closing transitions:

```tsx
<Drawer nomotion>
  <DrawerTrigger>
    <Button>Open navigation</Button>
  </DrawerTrigger>
  <DrawerContent title="Brewery navigation">
    <Vertlist>{/* Navigation items */}</Vertlist>
  </DrawerContent>
</Drawer>
```

`nomotion` is inherited by nested motion-aware components. An explicit `nomotion={false}` overrides an inherited `true` when the system preference allows motion. Without an inherited value, the default is motion enabled.

Disabling transitions does not disable component interactions or direct gestures. For example, Drawer can still be swiped even when `nomotion` is set; its swipe movement is not an opening or closing transition.
</Section>

<Section title="Reduced Motion">
Supported transitions respect the operating system or browser `prefers-reduced-motion: reduce` preference. When that preference is active, the transitions are removed automatically, including when a component explicitly sets `nomotion={false}`. A component prop does not override the user's system preference.

This documents the reduced-motion behavior of the shared transitions, not every possible animation in an application. Consumer-defined animations and other components should independently honor reduced-motion preferences. This behavior is one accessibility consideration, not a claim of blanket WCAG compliance.
</Section>
