    <Section title="Overview">
        The Breadcrumb component set provides a way to display the user's current location within a website's hierarchy. It consists of three components: Breadcrumb (container), BreadcrumbList (list container), and BreadcrumbListItem (individual links). These components are built on top of semantic HTML elements for better accessibility.
    </Section>

    <Section title="Breadcrumb">
        ### Description
        The root navigation component that wraps the breadcrumb elements.

        ### Usage
        ```tsx
        import {  Breadcrumb, 
                  BreadcrumbList, 
                  BreadcrumbListItem,
                  BreadcrumbSeparator } from "crafted-ui";

        <Breadcrumb>
          <BreadcrumbList>
            <BreadcrumbListItem>
              <a href="/">Home</a>
            </BreadcrumbListItem>
            <BreadcrumbSeparator />
            <BreadcrumbListItem>
              <span className="active" aria-current="page">Current Page</span>
            </BreadcrumbListItem>
          </BreadcrumbList>
        </Breadcrumb>
        ```

        ### Props
        The `Breadcrumb` component accepts the following props:
        
        | Prop | Type | Description |
        | --- | --- | --- |
        | className | string | Additional CSS class names |
        | children | ReactNode | Content of the breadcrumb container |
    </Section>

    <Section title="BreadcrumbList">
        ### Description
        A container for breadcrumb items, implemented as an unordered list for better accessibility.

        ### Usage
        ```tsx
        import { Breadcrumb, BreadcrumbList } from "crafted-ui";

        <Breadcrumb>
          <BreadcrumbList>
            {/* Breadcrumb items go here */}
          </BreadcrumbList>
        </Breadcrumb>
        ```

        ### Props
        The `BreadcrumbList` component accepts the following props:
        
        | Prop | Type | Description |
        | --- | --- | --- |
        | className | string | Additional CSS class names |
        | children | ReactNode | Content of the breadcrumb list |
    </Section>

    <Section title="BreadcrumbListItem">
        ### Description
        Represents an individual item in the breadcrumb navigation. Can be marked as active to indicate the current page.

        ### Usage with Links
        ```tsx
        import { Breadcrumb, BreadcrumbList, BreadcrumbListItem, BreadcrumbSeparator } from "crafted-ui";

        <Breadcrumb>
          <BreadcrumbList>
            <BreadcrumbListItem>
              <a href="/">Home</a>
            </BreadcrumbListItem>
            <BreadcrumbSeparator />
            <BreadcrumbListItem>
              <span className="active" aria-current="page">Current Page</span>
            </BreadcrumbListItem>
          </BreadcrumbList>
        </Breadcrumb>
        ```

        ### Usage with Custom Separators
        ```tsx
        import { Breadcrumb, BreadcrumbList, BreadcrumbListItem, BreadcrumbSeparator } from "crafted-ui";

        <Breadcrumb>
          <BreadcrumbList>
            <BreadcrumbListItem>
              <a href="/">Home</a>
            </BreadcrumbListItem>
            <BreadcrumbSeparator>→</BreadcrumbSeparator>
            <BreadcrumbListItem>
              <a href="/docs">Documentation</a>
            </BreadcrumbListItem>
            <BreadcrumbSeparator>→</BreadcrumbSeparator>
            <BreadcrumbListItem>
              <span className="active" aria-current="page">Components</span>
            </BreadcrumbListItem>
          </BreadcrumbList>
        </Breadcrumb>
        ```

        ### Props
        | Prop | Type | Default | Description |
        | --- | --- | --- | --- |
        | className | string | - | Additional CSS class names |
        | label | string | - | Optional aria-label override for icon-only links |
        | children | ReactNode | - | Content of the breadcrumb item |
    </Section>

    <Section title="Accessibility">
        The Breadcrumb component follows accessibility best practices by using semantic HTML elements:
        
        - The root component uses a `<nav>` element with an appropriate ARIA landmark
        - The list container uses a `<ul>` element for proper list semantics
        - Each item is a `<li>` element
        
        When implementing breadcrumbs, ensure that:
        
        1. Links have meaningful text (avoid "click here")
        2. The current page item should not be a link and should use `aria-current="page"`
        3. Separators are visually distinct and can be customized as needed
    </Section>
