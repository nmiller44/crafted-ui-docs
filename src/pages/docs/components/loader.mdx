<Section title="Props">
    | Prop | Type | Default | Description |
    | --- | --- | --- | --- |
    | size | "xs" \| "sm" \| "md" \| "lg" | "md" | Controls spinner dimensions and border thickness |
    | clr | "current" \| "foreground" \| "primary" \| "muted" \| "secondary" \| "accent" \| "destructive" \| "danger" \| "warning" \| "success" \| "info" | "current" | Controls spinner color token |
    | label | string | "Loading" | Screen-reader label announced in live region updates |
    | className | string | - | Additional CSS classes |

    Loader also accepts all standard HTML span attributes.
</Section>

<Section title="Accessibility">
    - Uses `role="status"` and `aria-live="polite"` for non-intrusive progress announcements
    - Includes screen-reader text via the `label` prop (defaults to "Loading")
    - For icon-only loading states, provide contextual labels like "Saving profile" or "Loading table rows"
</Section>
